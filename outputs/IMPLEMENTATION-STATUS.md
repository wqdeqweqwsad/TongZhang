# 同账：实际进度与验收缺口

当前为开发中的 SwiftUI 工程，不是已验收的完整 MVP。浏览器版本仅是早期视觉原型，不能代表原生应用功能完成度。

## 本轮代码改动

- 修复旅行账本详情仍出现全局日常记账入口的问题：全局新增仅在首页及账单出现，账本详情使用预选当前账本的工具栏入口。
- 账单统计和双方头像选择在辅助功能大字体下改为纵向布局；结算页统一主题背景并显示拖动指示器。
- 深色模式主按钮显式使用主题前景色，避免依赖系统自动选择文字颜色。以上布局和颜色改动尚待模拟器验证。
- 增加 GitHub Actions macOS 云端构建配置，并已在 GitHub Actions 的 iPhone 15 Simulator runner 上完成一次真实编译与 XCTest：run `35411424749`，job 结果为 `success`。仍未完成手动视觉验收和真机安装验收。
- 明确 iPhone 验收路径：云端签名构建并上传 TestFlight 后，可直接用现有 iPhone 验收；单独的 GitHub Actions 未签名产物不能安装到手机。
- 历史快照补充昵称、头像大小、邀请码及日期范围校验，与编辑入口共用规则；非法快照保留原数据并锁定修改。
- 邀请码严格要求六位 ASCII 数字，拒绝尾随换行及全角数字；消费拒绝非有限或超出 Foundation 常用日期范围的日期。
- 新增非法个人资料快照保护及日期校验回归测试代码，尚未运行 XCTest。
- 请客菜单显示实际昵称；账单统计金额单行缩放，删除提示明确保留历史结算。布局效果仍待原生验收。
- 本轮执行浏览器原型 JavaScript 语法检查、两个 plist 和共享 scheme XML 检查，均通过。环境仍无 Swift 和 Xcode，不能据此声明原生构建通过。
- `TongZhang-iOS-source.zip` 提供当前工程源码及运行说明，属于待 Xcode 验收版本。

- 首次安装默认未绑定；关系编辑标注本地模拟绑定，避免误以为已连接另一台手机。
- 标记结算前显示收付款人及金额确认，明确仅记录而不执行转账；余额发生变化时拒绝过期确认并要求重试。
- 增加结算确认期间余额变化的测试代码，尚未执行。

- 首页、账单及账本消费行支持打开详情，展示实际付款人、双方承担金额、分类、账本、日期和备注；详情支持确认删除。
- 删除提示说明余额会重算且历史结算转账保留；详情展示调用同一结算分摊引擎，未另写计算逻辑。原生交互仍待验证。

- 补齐应用与测试包的 executable、版本、包类型等 plist 字段，Bundle Identifier 改为构建变量。
- 工程指定 iOS SDK 和设备/模拟器平台，Debug 开启 ENABLE_TESTABILITY 和 -Onone，支持 XCTest 的 @testable import。
- 两个 plist、共享 scheme XML 及工程对象引用检查通过；Swift/Xcode 不可用，未执行构建。

- 快速记账由系统 Form 改为无卡片分区布局，突出金额、SF Symbols 分类网格、分段付款人及菜单分摊；成功保存提供轻触感反馈。
- 输入校验使用弹窗，避免键盘和滚动位置遮挡错误；关系页可滚动，底部预留新增按钮空间。
- 上述视觉调整仅完成源码，尚无原生截图或实际交互验证，不能据此判定高保真验收通过。

- 首页“查看全部”切换到账单，已平账时可打开结算历史；首页和结算页增加空状态。
- 记账金额初始为空并自动聚焦，提供取消入口；结算失败时保留页面显示错误。
- 外观设置支持系统、浅色和深色并持久化；移除未实现的 Face ID、导出等可点击样式占位。
- 首页和账单增加底部留白，仍需模拟器验证新增按钮与内容不重叠。

- 本地 JSON 快照保存消费、独立结算记录和本地关系状态。
- Preview 与普通状态测试关闭持久化，持久化测试使用独立 UserDefaults suite。
- 结算不再使用永久清零的布尔值；新消费与历史转账共同参与余额计算。
- 不参与结算的消费从余额计算中排除。
- 修正代付请客测试的收付款方向，界面文案使用实际计算结果。
- 补充重复结算、新消费、删除已结算消费和重启恢复测试代码。
- 添加 Combine 导入、共享 Xcode scheme，修正 HStack 调用 Text 专属修饰符的问题。
- 首页本月金额和记录数、账单页三项统计改为真实数据；移除首页模拟预算和增幅。
- 账单页支持前后月份切换，按实际日期降序分组，同一天的记录按时间降序排列。
- 金额显示使用整数商和余数，避免经过 Double；新增跨年和月边界筛选测试代码，尚未执行。
- 金额和比例输入采用完整格式校验，拒绝超过两位小数、尾随文字和超出范围的数值；单笔上限 999,999,999.99 元。
- Store 新增入口校验金额和分摊总额，消费数组改为只读发布；快速记账支持保存备注。
- 新增金额解析边界和无效分摊拒绝测试代码，尚未执行。
